プラグイン内のシェーダー(wgsl)はファイル数およびコード量が膨大になるため、以下の厳格な規則を用いて可読性と保守性を確保する。

1. 同一エフェクト内に同一動作があれば → そのエフェクトのディレクトリ内に共通参照用wgslを作り、関数化して各自参照
2. 複数エフェクトに跨って同一動作があれば → common/ 配下にwgslを作り、関数化して各自参照
3. (ほとんど)同じ動作をするpassがあれば → common/ に移して共通参照
4. 逆に、common/にあるが１つのエフェクトでしか使わない場合 → そのエフェクトのディレクトリに移す
5. 若干動作が異なるところでも、python側でのshader_defパラメータを使うことで大部分を共通化できる場合は、common/に移して共通参照させる

それを管理するpython側も同様に、共通化できる部分はcommon/に移して共通参照させる。
